# Fabio Ask Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let customers and staff ask Fabio relevant Southbrook/Odoo questions and receive permission-safe answers.

**Architecture:** Add a `southbrook.hermes.question` model in `southbrook_hermes` as the shared answer engine. Staff use a backend `Fabio > Ask` menu; customers use `/my/fabio` in the portal, where the controller scopes answers to the logged-in partner's kitchen projects. Answers are deterministic Odoo-data summaries in v1, with optional draft Fabio recommendations for follow-up actions.

**Tech Stack:** Odoo 19 models, QWeb portal templates, Odoo backend XML views, TransactionCase/HttpCase tests, existing `southbrook_hermes` and `southbrook_customer_portal` addons.
